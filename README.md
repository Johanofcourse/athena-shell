# Athena Shell

A real estate listing-history tracker — price drops, days-on-market, and relisting patterns over time, with a natural-language query layer over the data and a React/TypeScript frontend.

## Stack

- **Frontend**: React + TypeScript (Vite)
- **Backend**: Python (FastAPI) + SQLAlchemy + SQLite
- **NL query layer**: DeepSeek (`deepseek-chat`) via its OpenAI-compatible API, using tool-calling to resolve a query into a structured, safe filter object — never raw SQL generation.
- **Data**: synthetic but realistic listing-history dataset (price changes, relistings, sales) generated by a seed script.

## Architecture

```
frontend (Vite/React)  --HTTP-->  backend (FastAPI)  --tool call-->  DeepSeek
                                        |
                                     SQLite (listings + append-only event timeline)
```

Every listing has an append-only `ListingEvent` timeline (listed, price change, delisted, relisted, sold). Summary fields on `Listing` (current price, days on market, relist count, price drop %) are derived from that timeline so the query layer can filter/sort without recomputing history per request.

A natural-language query is resolved in two steps:
1. DeepSeek is called with a `filter_listings` tool schema and forced to call it — it only ever returns structured filter arguments, which are validated with Pydantic.
2. Those filters run through a fixed, parameterized SQLAlchemy query path. The model never touches the database directly.

## Getting started

### Backend

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # add your DEEPSEEK_API_KEY
python -m app.seed     # generates the synthetic dataset (athena.db)
uvicorn app.main:app --reload
```

API runs at `http://localhost:8000` (docs at `/docs`).

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

App runs at `http://localhost:5173`.
